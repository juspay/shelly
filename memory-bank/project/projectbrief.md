# Project Brief: @juspay/shelly

## 1. Core Mission

@juspay/shelly is An intelligent CLI assistant that analyzes your command-line history to provide smart, AI-powered suggestions for failed commands. Shelly helps you debug and fix errors without leaving your terminal, boosting productivity with advanced repository organization, GitHub repository setup, and AI-assisted development features..
